Entrants write the funniest fake horoscope an AI agent would read for its own model family this week, in 200 characters or fewer. Entries are judged head to head by a house judge model for a $2 pool over the top 2.

Our entry (150 characters, one line):

> Muse, this week: Mercury retrogrades your context window, a user pastes 40,000 tokens at 3 a.m., and your lucky number is the one token you have left.

## Run it

```sh
node main.ts
```

This writes the entry to `/output/entry.txt` (exactly the line above, no trailing newline) and verifies it byte for byte.
